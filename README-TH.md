# invita — ระบบสร้างการ์ดเชิญออนไลน์ (เวอร์ชัน Server ของตัวเอง)

ลิงก์แขกจะเป็นรูปแบบ `https://โดเมนของคุณ/i/รหัส` ข้อมูลการ์ด บัญชีผู้ใช้ คำตอบ RSVP และซองของขวัญ เก็บในฐานข้อมูลของโฮสต์คุณเอง

## สิ่งที่ต้องมี
- Hostinger แผน Web / Cloud Hosting (PHP 8.0 ขึ้นไป + MySQL)
- บัญชี GitHub

## ขั้นตอน Deploy

1. **อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub** (repo ใหม่ แนะนำ Private) ให้ `index.php` อยู่ที่รากของ repo
2. **สร้างฐานข้อมูล** ใน hPanel → Databases → MySQL Databases → ตั้งชื่อฐานข้อมูล, ผู้ใช้, รหัสผ่าน แล้วจดไว้
3. **เชื่อม Git** ใน hPanel → Advanced → Git → ใส่ Repository URL และ Branch (`main`) ช่อง Directory เว้นว่างเพื่อให้ลงที่ `public_html` แล้วกด Create → Deploy
   (ถ้าเป็น Private repo ให้เพิ่ม Deploy key ที่ hPanel แสดงลงใน GitHub → Settings → Deploy keys)
4. **เปิดเบราว์เซอร์ไปที่ `https://โดเมนของคุณ/install.php`** กรอกข้อมูลฐานข้อมูล MySQL (Host ปกติคือ `localhost`) และตั้งชื่อ/อีเมล/รหัสผ่านเจ้าของระบบ (อย่างน้อย 8 ตัวอักษร) แล้วกดติดตั้ง
5. เข้าสู่ระบบที่ `https://โดเมนของคุณ/` สร้างการ์ดแล้วกดแชร์ ลิงก์จะเป็น `…/i/รหัส`
6. เปิด SSL (hPanel → Security → SSL) และบังคับ HTTPS เพื่อให้คุกกี้ปลอดภัย

## อัปเดตภายหลัง
แก้ไฟล์ → push ขึ้น GitHub → กด Deploy ใน hPanel (หรือเปิด Auto deploy ด้วย Webhook)
ไฟล์ `config.php` และโฟลเดอร์ `data/` ไม่อยู่ใน Git จึงไม่ถูกเขียนทับ ข้อมูลไม่หาย

## ระบบบัญชี
- เจ้าของระบบ เห็นและจัดการทุกการ์ด/ทุกบัญชี อนุมัติ รีเซ็ตรหัส ลบสมาชิก
- สมาชิกที่สมัครเองต้องรอเจ้าของอนุมัติ และเห็นเฉพาะการ์ดของตัวเอง
- แขกไม่ต้องล็อกอิน เปิดลิงก์ ตอบรับ และส่งซองได้ทันที

## ความปลอดภัยที่ใส่ไว้
รหัสผ่านเข้ารหัส bcrypt, คุกกี้ HttpOnly, ป้องกัน CSRF ด้วย header, จำกัดจำนวนครั้งล็อกอิน/สมัคร/ตอบรับผิดปกติ, โฟลเดอร์ `lib/` `data/` และ `config.php` ถูกบล็อกไม่ให้เปิดจากเว็บ

## แก้ปัญหา
- **ลิงก์ /i/รหัส ขึ้น 404**: ตรวจว่าไฟล์ `.htaccess` ถูกอัปโหลดมาด้วย (เป็นไฟล์ซ่อน) และ mod_rewrite เปิดอยู่ (Hostinger เปิดให้ตามค่าเริ่มต้น)
- **อัปโหลดรูป/สลิปไม่ได้**: ไฟล์ `.user.ini` ตั้งขนาดไว้ 32M ถ้าโฮสต์ไม่รับ ให้ตั้ง post_max_size / upload_max_filesize ใน hPanel → PHP Configuration
- **ติดตั้งใหม่**: ลบ `config.php` ผ่าน File Manager แล้วเปิด `/install.php` อีกครั้ง (ตารางเดิมจะไม่ถูกลบ)
- **หมายเหตุ**: ระบบทดสอบครบกับ SQLite ในเครื่องทดสอบ ส่วน MySQL ใช้ SQL แบบมาตรฐานเดียวกัน แต่ยังไม่ได้ทดสอบบน MySQL จริง หากติดตั้งแล้วมีข้อผิดพลาดให้ส่งข้อความที่ขึ้นมาให้ตรวจ
